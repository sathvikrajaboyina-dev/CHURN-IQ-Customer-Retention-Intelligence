# Power BI Dashboard

This directory contains the interactive CHURN//IQ Customer Retention Intelligence dashboard.

## Report

`CHURN_IQ_Final.pbix`

## Dashboard Pages

1. Executive — overall customer and churn performance.
2. Churn Drivers — churn rates by contract, payment method, internet service, and other customer characteristics.
3. Retention Radar — high-risk customer prioritization and estimated customer value.

## Interactive Features

- Interactive slicers
- Customer Economic & Risk Map
- Custom customer tooltip
- Customer-detail drill-through
- Customer value and risk segmentation
