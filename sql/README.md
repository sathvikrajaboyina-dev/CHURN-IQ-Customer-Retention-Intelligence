# CHURN//IQ SQL Analysis

This directory contains the SQL queries used to validate customer data, analyze churn drivers, compare customer segments, and identify active high-risk retention opportunities.

## Database

PostgreSQL — Supabase

## Table

`public.telco_churn`

## Query execution order

Run files `01` through `10` in numerical order when reproducing the complete analysis.

These queries describe observed customer patterns and associations; they do not establish causation.
